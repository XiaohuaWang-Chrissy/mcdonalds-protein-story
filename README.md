# McDonald’s chases customers who are trying to slim down

A scrolling story site built with SvelteKit. As you read, a sticky stock chart at the top
follows the story: it moves a playhead to the date each paragraph talks about and zooms in
on short periods.

## Run

```bash
npm install
npm run dev      # local dev server
npm run build    # static site in build/
```

## Updating the article or data

The article text, embedded figures and stock prices are generated by `scripts/extract.py`
from the source files in the parent folder (the PDF of the article and the stock spreadsheet).
Run it from this folder with `python3 scripts/extract.py`. It needs poppler (`pdftotext`,
`pdfimages`) and `openpyxl`.

Data source: Google Finance
